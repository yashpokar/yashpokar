```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # dist/ with rss.xml, sitemap.xml and a 404.html fallback
```

**Add a post:** drop a Markdown file in `src/content/posts/` with frontmatter:

```md
---
title: Your title
summary: One or two sentences shown on cards and in the RSS feed.
date: 2026-10-26
tags: [Go, Kubernetes]
featured: false   # optional
draft: false      # drafts render in dev only
---

Body in GitHub-flavoured Markdown. Code blocks get syntax highlighting and a copy button.
```
